# 有界搜尋指引包

- `SEARCH_SCOPE_RULES.md`：可直接交給 agent 的搜尋約束。
- `scoped_search.py`：可選的有界本機搜尋工具，Python 3.9+，無第三方依賴。

解壓即可使用，不需要安裝插件或修改全局設定。實際強制採用指引需由任務或專案引用；Python 不會攔截其他命令，也不是安全隔離系統。不具備競態防護，不應在惡意或同時變動的目錄中作為安全邊界。

`--glob` 比對檔名；`--text` 使用區分大小寫的字面文字。文字只讀取 UTF-8，其他編碼與大型檔案會回報跳過。預算可透過 CLI 參數調整，磁碟根目錄與使用者主目錄始終拒絕。

此工具為本次新增，不是既有 research-token-guard 的附屬程式。
