# 有界搜尋規則

## 用途與適用範圍

這是一份可交給 agent 的任務指引。只有在任務或專案明確引用時才適用；不自動安裝成全局規則，也不攔截其他工具。

目標是避免為了找一個檔案而遍歷整個磁碟、使用者目錄或大型專案。限制搜尋範圍與限制輸出量是兩件事：截斷輸出或使用 token guard，不能取代範圍控制。

## 必須遵守的搜尋順序

1. **先用已知位置。** 優先使用使用者提供的路徑、現有文件引用、manifest、專案設定或上一個工具結果。已知檔案直接讀取，不重新搜尋。
2. **先看一層。** 不知道具體位置時，先列出候選目錄的直接子項，選定相關子目錄。
3. **先找檔名，再找內容。** 優先搜尋指定檔名、副檔名或檔名模式；內容搜尋需指定相關目錄及檔案類型。
4. **逐步擴大。** 在未找到且有合理線索時，自主擴大到下一個相關目錄，每次保留明確根目錄與限制。不因一次未命中就跳到全盤搜尋。
5. **得到足夠證據就停止。** 不為了「可能還有」繼續掃描無關位置。

## 禁止的預設行為

- 不以磁碟根目錄、檔案系統根目錄或整個使用者主目錄為遞迴搜尋起點。
- 不跨多個磁碟或遞迴搜尋整個插件快取、研究資料區、全部歷史輸出來定位單一目標。
- 不跟隨 symlink、junction 或其他重新導向的目錄，跨出指定搜尋根目錄。
- 不預設讀取 credentials、私鑰、`.env`、個人配置或無關私人資料。
- 不把 `Select-Object -First`、輸出截斷、壓縮摘要或 token guard 當成搜尋本身有界的證據。
- 不把沒有搜尋到解讀成不存在；必須說明實際查過的範圍及是否碰到限制。

## 搜尋預算

一般定位任務，每輪預設最多深度 4、檢查 5,000 個目錄項目、讀取 2,000 個候選文字檔、回傳 50 個結果。讀取單檔上限 1 MiB；大型檔案另做指定區段讀取。

預設排除 `.git`、依賴目錄、虛擬環境、快取、建置產物及大型執行輸出。目標確實在其中時，只對那個具體子目錄執行搜尋。

達到預算時停止並回報限制，根據現有線索縮小下一輪範圍。若任務確實需要完整盤點，使用者明確要求或既有授權涵蓋該盤點即可執行，但仍須限定目標、排除項與資源預算。沒有該授權時，不進行全盤搜尋。

## 工具選擇

在已限定的目錄內，優先用 `rg --files` 找檔名、`rg -n` 找內容。不要從大目錄開始，再靠管線截斷結果。

需要明確遍歷預算時，可使用同包的 `scoped_search.py`：

```powershell
python scoped_search.py --root "指定的具體目錄" --glob "*manifest*.json"
python scoped_search.py --root "指定的具體目錄" --glob "*.md" --text "關鍵字"
```

Python 工具使用字面文字比對，輸出 JSON；`complete: false` 表示碰到限制、排除項或讀取問題，不可聲稱完整搜尋。它只能限制自己的搜尋，無法阻止 agent 改用其他工具，也不會判斷任務授權。

## 回報格式

簡短說明：查過哪些目錄、採用哪些條件、找到什麼，以及未涵蓋的範圍或限制。不要將大量目錄清單或無關內容灌入對話。
